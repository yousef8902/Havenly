# Havenly Home Finder

Design and build a complete high-fidelity responsive web application UI/UX for a modern short-term property rental platform.

The product is an Airbnb-inspired marketplace where:

- Guests discover, search, filter, and book properties.

- Hosts create and manage property listings and booking requests.

- Administrators manage users, listings, bookings, and platform activity.

IMPORTANT:

This is an MVP designed for a university graduation project, so prioritize clarity, usability, realistic workflows, polished visual design, and a manageable scope. Do not copy Airbnb's branding, layout, colors, or visual identity. Create an original premium product identity.
